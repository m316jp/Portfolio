# 「どの生成AIがおすすめ？」と聞かれたら、私が答えていること

『AI×家事』（扶桑社）著者・宮崎真理／公開 2026-10-21

「生成AIを使ってみたいんですけど、何を使えばいいですか？」

最近、本当によく聞かれる質問です。

ChatGPT、Gemini、Claude。いろいろあるけれど、結局どれがいいの？ 無料版でも十分？ 有料版にしたほうがいい？

私は普段、家事や子育て、仕事など、生活のさまざまな場面で生成AIを使っています。その活用法を本や記事、SNSで紹介していることもあって、使い方について相談される機会も増えました。

そう聞かれたとき、私は「まずはChatGPTを一つ。無料版から始めて、しばらく使い続けてみて」と答えています。

私自身は2026年10月時点で、ChatGPTとClaudeの両方に課金して使っています。それでも最初は一つでいいと考えるのは、サービスを比べることより、一つを使い続けて自分の頼み方が変わっていくことのほうが、私には大きかったからです。

ただ、その前に確かめてほしいことがあります。相談を受けていると、ChatGPTを使っているつもりで、実は別のアプリを使っていた、という場面に何度か出会いました。

## それ、ChatGPTじゃないです

以前、「私もチャッピー使ってます！」とスマートフォンの画面を見せてもらったことがありました。

ところが、そこに表示されていたのは、OpenAIのChatGPTではなく、別のよくわからないAIアプリ。

また別のときには、ChatGPTの話をしているつもりが、実際に使っていたのはGoogleのGeminiだった、ということもありました。

ChatGPTの愛称として「チャッピー」という呼び方が広まっていますが、AIと会話できるサービスをまとめてそう呼んでいる人もいるのかもしれません。

もちろん、ChatGPT以外を使うことに何の問題もありません。ただ、自分がどのサービスを使っているのかは、知っておいたほうがいいと思います。

というのも、生成AIはどれを使っても同じ結果になるわけではないからです。

## 同じ生成AIでも、モデルによって性能は違う

以前、私が紹介したAIの活用法を試して、「同じようにやってみたけれど、うまくできなかった」と相談されたこともあります。

詳しく聞いてみると、私とは違う生成AIを使われていました。

実は、ChatGPTやGemini、Claudeといったサービスの違いだけでなく、それぞれのサービスの中で使われている「AIモデル」によっても性能は異なります。

モデルとは、質問を読み取って答えを組み立てる、生成AIの中心の仕組みです。同じサービスでも、無料版か有料版か、どのモデルを選んでいるかによって、使われるモデルが変わることがあります。

その性能は近年、大きく進化しています。スタンフォード大学の研究所が公表した[『AI Index Report 2026』](https://hai.stanford.edu/ai-index/2026-ai-index-report)でも、AIの推論能力やプログラミング能力などが急速に向上していることが報告されています。

私自身、モデルが進化するにつれて、こちらの意図をくみ取る力や、複雑な条件を整理して考える力が向上していると感じています。

ただし、ここでいう「賢さ」と、答えの「正確さ」は同じではありません。

AIは複雑な問題を解ける一方で、人間には簡単に思える問題を間違えることもあります。同じレポートでは、国際数学オリンピックで金メダル水準の成績を出すAIがある一方で、アナログ時計の時刻を正しく読めたのは、最も成績のよいモデルでも約半分だったという例が紹介されています。

日常のちょっとした質問や文章の言い換えなら、必ずしも最新の高性能モデルを使う必要はないでしょう。

一方、複雑な資料の分析やプログラミングなどでは、モデルによる性能差が結果に大きく表れることがあります。

だからといって、常に最新モデルを追いかける必要はありません。

**私が気にしているのは、最新かどうかより、やりたいことに対して性能が足りているかどうかです。**

「生成AIって思ったほど使えないな」と感じたら、質問の仕方だけでなく、使用しているモデルを見直してみるのも一つの方法です。

## 結局、どの生成AIを選べばいいの？

代表的な生成AIには、OpenAIのChatGPT、GoogleのGemini、AnthropicのClaudeなどがあります。

文章作成や相談、調べ物、資料の要約、プログラミングなど、幅広い用途に使えます。

もちろん、それぞれに特徴がありますが、私は日常的な用途では、共通してできることがかなり多いと感じています。

各社の開発競争は激しく、以前は特定のAIだけが得意としていたことも、ほかのAIでできるようになるなど、機能が重なってきています。

私自身は現在、ChatGPTとClaudeの両方に課金していて、利用割合はおよそ6対4です。

ただ、この割合はしょっちゅう変わります。新しいモデルや機能が登場するたびに、使い心地や得意なことも変わっていくからです。

二つ使っていると、同じ質問をして回答を比較できるのも便利です。特に文章を練ったり、提案を検討したりするときには、一方になかった視点がもう一方から得られることもあります。

ただし、二つのAIが同じことを言ったからといって、それが正しいとは限りません。事実の確認は別に必要です。

こうした違いを比較するのは面白いのですが、これからAIを使い始める人が、最初から複数のサービスを使い分ける必要はないと思っています。

今から一つ選ぶなら、私がおすすめするのはChatGPTです。文章での相談だけでなく、写真や音声、ファイルを使ったやり取りなど、幅広い用途を一つのサービスで試せます。

ほかのAIに興味が出てきたら、そのときに試せばいいと思います。

**最初は一つで十分。でも、ずっと一つである必要もありません。**

## 無料版と有料版、どちらを使えばいい？

ChatGPTは、無料版でも文章作成や相談、画像やファイルを使ったやり取りなど、さまざまなことができます。

ただし、利用できるモデルや機能、使用回数には制限があります。

日常のちょっとした相談なら、無料版で十分という人も多いでしょう。一方、複雑な作業を頻繁に頼みたい人にとっては、有料版のほうが便利な場合があります。

私としては、まず無料版を使ってみて、面白いと感じたら、一度有料版を試してみるのもいいと思っています。

ただし、**お金を払えば、必ず正確な答えが得られるわけではありません。**

生成AIは、学習した情報のパターンや入力された文脈をもとに回答を生成します。必ずしも、検証済みの事実だけを取り出して答えているわけではありません。

そのため、もっともらしい誤情報を生成してしまう「ハルシネーション」が起こります。

2025年にOpenAIの研究者らが発表した[論文](https://openai.com/ja-JP/index/why-language-models-hallucinate/)では、この現象が起こる背景として、わからないと認めるよりも、推測して答えることが評価されやすい学習・評価の仕組みが指摘されています。

モデルの進化によって誤答が減ることはありますが、高性能なモデルでも間違いは起こります。

有料版の価値は、単に正確性だけでなく、利用できるモデルや機能、使用量などにもあります。

自分にとって必要かどうかを、実際に使いながら判断すればいいと思います。

## 一つのAIを使い続けることにも意味がある

私が最初は一つの生成AIを使ってみることをおすすめするのには、理由があります。

一つは、以前の会話で伝えた情報を、次の相談にも生かせることです。

例えばChatGPTには、設定に応じて過去の会話や関連情報を参照し、家族構成や好み、以前相談したことなどを踏まえて回答するメモリ機能があります。

もちろん、すべてを正確に覚えているわけではありませんし、記憶した情報が古くなったり、間違っていたりする可能性もあります。それでも、毎回一から説明する手間が減るのは便利です。

ただ、私がそれ以上に価値を感じているのは、**使う側の経験が積み重なっていくこと**です。

何度も使っていると、AIが得意なことや苦手なこと、どう頼めば期待する結果に近づくのか、どんな回答は自分で確認する必要があるのかが、少しずつわかってきます。

さらに、「こんなこともAIに相談できるんだ」と気づく機会が増えていきます。

すると、日常の中で面倒なことに出合ったとき、「これもAIを使って解決できないだろうか」と考えるようになります。

私自身、生成AIを使い続けてきた中で、一番大きな変化はここにあると感じています。

もちろん、ただ使う回数が増えれば、自然に上達するわけではありません。AIの回答を鵜呑みにせず、結果を確かめ、必要に応じて頼み方を変える。その繰り返しがあって、使う側の経験になるのだと思います。

Microsoft Researchなどの研究者らが知識労働者319人に行った[調査](https://doi.org/10.1145/3706598.3713778)でも、生成AIを信頼している人ほど、自分で批判的に考えることが少なくなる傾向が報告されています（参加者の自己申告にもとづく調査です）。

**AIが自分に合った回答を返しやすくなるだけでなく、自分もAIをより適切に使えるようになっていく。**

私は、この両方に価値があると思っています。

## AIに詳しくなることが目的ではない

生成AIを使い始めるのに、特別な知識や完璧な指示文は必要ありません。

「今日の夕食、何にしよう」「この学校のお知らせ、結局何をすればいいの？」「このメール、どう返信しよう」

そんな身近なことから相談できます。何を聞けばいいか迷う場合の考え方は、[生成AIに何を聞けばいい？](https://miyazakimari.com/articles/what-to-ask-generative-ai/)に書きました。

使い続けた先で私が得たのは、作業が速くなったことだけではありません。以前なら自分には難しいと思っていたことでも、AIに相談しながら、自分で解決方法を考えられるようになりました。家庭の不便をどう仕組みにしてきたかは、[生成AIで家庭の不便を仕組みにする](https://miyazakimari.com/articles/generative-ai-home-systems/)にまとめています。

生成AIを使う目的は、生成AIに詳しくなることではありません。

**自分の暮らしを、自分で便利にしていくこと。**

最後に、ChatGPTを使うなら、入口は公式サイトの[chatgpt.com](https://chatgpt.com/)です。スマートフォンのアプリは、開発元が「OpenAI」になっているかで見分けられます。

せっかくChatGPTを使おうと思ったのに、気づいたら別のアプリを使っていた、ということのないように。
