## 保管について

`archive/` は再編集用の元画像、`drafts/` は未公開原稿、`design/exports/` は生成画像の保管先。これらは `.gitignore` で除外しており、Gitへpushしても新しく公開されない。ローカル保管のため、必要な元データは別途通常のPCバックアップで保全する。
